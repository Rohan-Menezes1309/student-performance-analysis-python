Student Performance Analysis using Python

This Project analyses student academic performance using Python and data visualization techniques.

This dataset includes information about student study habits, failures, attendance and final grades.

Tools used include:
1. Python
2. Pandas
3. matplotlib
4. seaborn

Key Insights:
1. Students with more study time acheived higher grades.
2. Past academic failures affect performance.
3. Internet access was associated with slightly higher grades.
4. High absences were linked to declining performances.

Visuals:
The project includes,
1. Grade distribution histogram.
2. Study time v/s grade bar chart.
3. Failures v/s grade bar chart
4. Internet Access v/s grade bar chart
5. Absences v/s grade scatter plot

Conclusion:
Study habits such as study time, attendance and past performance play an important role in academic success.
